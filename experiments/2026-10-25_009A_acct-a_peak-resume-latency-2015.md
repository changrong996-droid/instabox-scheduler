## 操作序列（可复现）
1. API 政策巡检：`instabox_api.py ls`（5 台状态与规格）、
   `usage`（限额与存储）、`snapshots`（快照清单）。
2. 恢复 test-1：`instabox_api.py resume test-1 --wait`，
   以 API 操作时间戳计时（创建→runStartedAt→succeeded）。
3. 恢复后在 test-1 上执行：`date -u`、`uptime -s`、`uptime`，
   逐字记录输出，与 14:15 样本做前后对照。
4. 暂停 test-1：`instabox_api.py suspend test-1 --wait`，
   确认回到 suspended；最终确认 5 台全部 suspended。

方法说明：本轮首次改用 API 路径操作恢复/暂停（前两轮为
控制台点击，分钟精度）。API 返回的操作时间戳为秒级，
恢复延迟不再是 60 秒上界，而是精确到 0.01 秒的实测值；
两种路径测的是同一个恢复操作，数值可比，但精度不同，
跨轮比较时以前两轮的上界为准。
