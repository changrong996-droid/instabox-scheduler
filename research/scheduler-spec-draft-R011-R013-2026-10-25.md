## R-011 单机 lease：同一时间只有一个控制器能动一台机（Fly Machines lease / suspend / wait）

- 规则正文（提议）：调度器给每台机器发一个 lease，记录在 CLAIMS.md 的同一行里：机器名、持有人（ACCT-A / ACCT-B）、作业编号、开始时间、到期时间。lease 有效期内，另一方不得启动、恢复、暂停、销毁这台机，也不得在它上面开新作业。lease 到期或持有人主动释放后，他人才可接手。
- 我们的落法（无 API，只能文件模拟）：Fly Machines 的 lease 是平台端点，我们没有；用 CLAIMS 登记 + 心跳轮询模拟。suspend 对应 InstaBox 暂停（A3 已验证是冻结，见 R-007），wait 对应心跳轮询等状态变化，不是长轮询。
- 到期时间（提议，未定）：一个心跳间隔——夜间 2 小时、日间 6 小时；到期未续即视为释放。续 lease 的方式是心跳轮里在同一行更新到期时间，不另开登记。
- 让位时的处理：人类真实任务征用时（协议 7.6），lease 立即作废，状态改为“中止-让位”，不等待到期。
- 触发条件：任何跨账号 / 跨作业使用同一台机之前；单账号单作业内不强制。
- 来源：Fly Machines lease / suspend / wait（`superfly/flyctl`，Machines 为平台 API，无独立仓库，Apache-2.0）；对应现有 R-001（配额）、R-007（暂停冻结）。
- 置信度：低（草案，语义借用，未实测）
- 状态：草案-待拍板

## R-012 暂停 / 让位前先写 checkpoint，中断后从 checkpoint 续跑（LangGraph checkpoint / interrupt）

- 规则正文（提议）：任何可能中断的操作之前——暂停机器、做快照、让位、以及超过 30 分钟的任务切块——先把 checkpoint 落盘，再执行中断。恢复时从 checkpoint 的下一步继续，不从头重跑；checkpoint 缺失时按重启处理，并在实验记录里注明“无 checkpoint，重跑”。
- checkpoint 写什么（提议）：作业编号、当前步骤、已完成的输入/输出、下一步、落盘时间。落盘位置提议为两处：机器内 `/data` 下的作业目录（随暂停冻结保留，A3 已验证文件完整），以及仓库内该实验的记录文件（供心跳轮离线核对）。
- 中断点（提议）：暂停前、快照前、让位前三处为必写点；其余长任务每完成一个切块写一次。
- 触发条件：任何超过 30 分钟闲置或跨暂停的任务规划；与 R-004 / R-007 同触发条件。
- 来源：LangGraph checkpoint / interrupt / durable execution（`langchain-ai/langgraph`，MIT）；对应现有 R-004、R-007。OpenAI Agents SDK 的工具审批式人工介入（可暂停运行、从保存状态恢复）是同一类原语，记为参考，不另立规则。
- 置信度：低（草案，语义借用，未实测）
- 状态：草案-待拍板

## R-013 任务认领要原子化，限速按组算，重试指数退避（BullMQ rate limit / 原子认领 / 重试退避）

- 规则正文（提议）：认领一个任务时，“取任务并标记 active”必须是一次原子操作，不得先取后标、留出两个控制器同时认领同一任务的窗口。我们的落法（无 Redis/Lua，只能文件模拟）：认领 = 在 CLAIMS.md 写一行认领记录并提交一次；提交前先查该机器/该任务是否已有 active 认领，有则放弃本次认领，不重试抢占。
- 限速（提议）：按账号分组限速，沿用 R-002 的实测值——同一账号批量启动每分钟最多 3 次；第 4 次被拒时等待至少 70 秒再重试。BullMQ 的原生 rate limit（含按组限速）是这一条的语义来源，数值仍以我们的实测为准，不抄框架默认值。
- 重试退避（提议，未定）：认领冲突或启动被拒时按 70 秒、140 秒、280 秒指数退避，最多 3 次；3 次仍失败则把任务放回队列、记一次失败，不无限重试。70 秒起步取自 R-002 的现有等待值，后两档为提议值，待实测收紧。
- 触发条件：任何批量创建 / 批量恢复 / 多作业并行认领。
- 来源：BullMQ rate limit、Lua 原子“取任务并标记 active”、retry 指数退避（`taskforcesh/bullmq`，MIT）；对应现有 R-002。K8s Job 的 backoffLimit、Celery 的任务级限速记为参考，不另立规则。
- 置信度：低（草案，语义借用，未实测；退避后两档纯提议）
- 状态：草案-待拍板
